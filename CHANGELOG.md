# Changelog

## 0.5.0-rc.1

- Shorter interface copy, compact Discover/Gallery/Collections headings and controls.
- Fewer unnecessary card renders, one-pass flowing-grid columns, retained lazy
  images and linear duplicate filtering across and within result pages.
- Windows x64 per-user installer and complete application ZIP with leaf icon.
- Hardened executable fuses, embedded ASAR integrity, strict package contents,
  payload verification and release checksums.
- Explicit packaged offline demo, isolated profile launch option, packaged-app
  smoke checks, pinned Windows CI, upgrade/backup and dependency review guidance.
- Maintainer/contact: JustyPixels via GitHub Issues.

This is an unsigned prerelease. It retains all earlier booru search, encrypted
credential, archiving, offline Gallery and portable local Collection features.
Database v3, media sidecars v1 and collection snapshot v1 are unchanged.
Authenticated real-key live access and physical power-loss recovery are unverified.
See LOG.md for earlier phases and actual verification results.
